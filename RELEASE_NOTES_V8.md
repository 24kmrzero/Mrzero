# V8 Release Notes

This release expands the existing V7 signal system into the complete 24K Excellence platform workflow.

## Added

- Email verification state and Check Your Email flow
- Preserved course/referral intent across signup, verification and login
- Clean GitHub Pages route folders
- First-touch Link Manager and conversion reporting
- Global user access, expiry, grace, lifetime and PIN management
- Bulk access extension excluding lifetime users
- Free and paid course types, discounts and public course catalogue
- Ordered modules, lessons and progress
- Admin enrollment management
- Student notifications and access-status panels
- Email queue with repeat-send deduplication
- Optional Resend Edge Function for course/payment/live-class emails
- Expanded Admin Dashboard KPIs
- Full chart/article details and clear image containment

## Preserved decisions

- No Mentor Panel
- No attendance system
- Live Google Meet classes
- Instructor default: Malik Zameer
- Course resources optional from Admin
- No individual per-student Signals/Charts/Articles toggles
- No Copy Signal or WhatsApp Copy button
- PipSePaisa cross-project signal sync remains deferred
