24K MR ZERO — V12.00 MASTER OPERATIONS
=======================================

This is a cumulative incremental patch for the uploaded V10.40 project.
It includes the prior V11.13 email system, V11.14 tracked free enrollment,
and the new V12 Master Operations integration.

DO NOT delete your existing Supabase project or existing Infinity payment Edge Functions.

1) WEBSITE FILES
----------------
Upload/overwrite the contents of this patch at your website repository root.
Preserve the same folder structure.

2) SUPABASE SQL — RUN IN THIS ORDER
-----------------------------------
A. If V11.13 email SQL was NOT previously run:
   24_EMAIL_SYSTEM_V11_13.sql

B. Then run:
   25_MASTER_OPERATIONS_V12.sql

V12 SQL is additive and is designed to preserve existing production data/history.
It adds/updates the operational tables, RLS, RPC compatibility layer, Team/Finance/
Tracking/EA/Mentor/Live Desk systems and required policies/functions.

3) EDGE FUNCTIONS — DEPLOY/REDEPLOY
------------------------------------
supabase functions deploy process-email-queue --no-verify-jwt
supabase functions deploy free-course-enroll --no-verify-jwt
supabase functions deploy audit-event --no-verify-jwt

Required/used secrets:
- RESEND_API_KEY
- EMAIL_FROM
- SITE_URL
- EMAIL_QUEUE_SECRET

Optional:
- FREE_COURSE_SLUG  (if you want to force one specific free course)

Supabase supplies SUPABASE_URL and service-role environment values to Edge Functions.

4) AUTH EMAILS / SMTP
----------------------

- Confirm signup
- Invite user
- Reset password
- Change email

If you already configured these in the Supabase dashboard, do not overwrite them unless desired.
