# 24K Excellence Complete Platform V8

Production-oriented GitHub Pages + Supabase package for the 24K Excellence public website, Student Panel and Admin Panel.

## Main scope

- Public website and dynamic course catalogue
- Signup, email verification screen, login, forgot/reset password and logout
- Student Dashboard, Signals, Charts, Articles, Courses, Progress, Payments, Announcements, Notifications, Access Status, Profile and Support
- Admin Signals, Charts, Articles, Courses, Modules/Lessons, Google Meet sessions, optional resources, enrollments, payments, users/access, Link Manager, email delivery queue and support
- No Mentor Panel
- No attendance system
- No Copy Signal / WhatsApp Copy button
