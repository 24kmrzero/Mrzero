# Final Feature Scope

## Student portal

- Dashboard with latest signal, next class, course access, announcements and payment alerts
- Signals with active/TP hit/SL hit/Breakeven/Closed history and win-rate summary
- Charts with symbol/timeframe search
- Articles with full reading modal
- Courses with Upcoming/Active/Completed status
- Session cards showing class title, topic, date, time, duration and status
- Google Meet link locked until Admin approves payment
- Optional resources controlled by Admin
- Payment receipt upload and status history
- Announcements
- Profile settings
- Support tickets
- Required Risk Disclaimer acceptance

## Admin portal

- Dashboard statistics
- Signals add/edit/delete and performance status
- Chart image upload and analysis
- Article publishing
- Student announcements
- Course creation, price, dates and status
- Google Meet sessions with private links
- Optional course resource upload
- Receipt view, Under Review, Approve and Decline actions
- Automatic course unlock after approval
- Registered student list
- Support request status
- Payment methods and account instructions

## Explicitly excluded

- Attendance system
- Individual Signals/Charts/Articles access controls per student
- Recorded class promise or recording library
