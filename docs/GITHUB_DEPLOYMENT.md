# GitHub Pages Deployment — 24K Excellence V9

Extract the ZIP and upload everything inside the extracted folder directly to the root of the GitHub repository `Mrzero`.

Do not create an extra nested folder. The repository root should visibly contain:

- `index.html`
- `login.html`
- `check-email.html`
- `student-dashboard.html`
- `admin-dashboard.html`
- `admin-login.html`
- `admin.html`
- `app.css`
- `styles.css`
- `assets/`
- `admin/`
- `sign-in/`, `sign-up/`, `free-course/`, `courses/`, `charts/`, `articles/`
- `.nojekyll`

After upload, wait 1–3 minutes, open the live URL and hard refresh with `Ctrl + F5`.
