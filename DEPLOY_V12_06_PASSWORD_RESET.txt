24K MR ZERO — V12.06 PASSWORD RESET FIX

WHAT THIS FIXES
- Removes the word “Supabase” from the Student Forgot Password popup.
- Uses a branded server-side recovery email as the primary reset flow.
- Recovery email is sent through Resend using RESEND_API_KEY + EMAIL_FROM.
- Keeps native Auth reset as a browser fallback if the custom Edge Function is unavailable.
- Adds direct token_hash verification on /reset-password/.
- Adds rate limiting without storing raw email/IP in the rate-limit table.

DEPLOY
1) Upload/overwrite the files in this patch at the same paths.
2) Supabase SQL Editor: run 26_PASSWORD_RESET_EMAIL_V12_06.sql once.
3) Deploy Edge Function:
   supabase functions deploy request-password-reset --no-verify-jwt
4) Edge Function secrets must exist:
   RESEND_API_KEY
   EMAIL_FROM
   SITE_URL=https://www.24kmrzero.com
5) Hard refresh the website (Ctrl+Shift+R).
6) Test Forgot Password with a real existing account.

IMPORTANT
- EMAIL_FROM must be a sender/domain verified in Resend.
- The public response does not reveal whether an email account exists.
- The new primary flow does NOT depend on the Auth SMTP template for Forgot Password delivery.
